1. ORGANIZAÇÃO COM GIT

Foi explicado como criar uma nova branch para alterar o projeto sem modificar diretamente a branch principal.

Criar e entrar na nova branch, porem nao utilizada ainda:

git checkout -b melhorias-site

Depois de concluir as mudanças:

git add .
git commit -m "Atualizações da landing page"

Voltar para a branch principal:

git checkout main

Adicionar as mudanças da nova branch:

git merge melhorias-site

Enviar para o GitHub:

git push origin main
